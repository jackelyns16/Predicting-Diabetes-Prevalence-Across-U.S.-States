# Predicting-Diabetes-Prevalence-Across-U.S.-States
Used SQL to extract, clean and aggregate the CDC Chronic Disease Indicators dataset into a 55-state analytical table.
Performed machine learning analysis in WEKA using Linear Regression, Logistic Regression, J48, and clustering. 
Identified top behavioral and socioeconomic predictors of diabetes prevalence, including smoking rate, obesity rate, short sleep and disability rate
Used CorrelationAttributeEval to select features most strongly associated with diabetes
Demonstrated that classifcation models performed poorly due to 47 unique target values
Communicated state-level diabetes risk patterns and public health implications for targeted preventive interventions
